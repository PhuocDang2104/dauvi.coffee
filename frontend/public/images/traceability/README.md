# Ảnh Traceability Spotlight

Có thể thay trực tiếp năm file SVG trong thư mục này bằng ảnh thật, giữ nguyên tên file để không phải sửa code:

- `region-gia-lai.svg`: đồi cà phê Gia Lai, ánh sáng sớm, tông xanh bazan.
- `region-dak-lak.svg`: cao nguyên và vườn Robusta Đắk Lắk, tông đất đỏ–xanh rừng.
- `region-bao-lam.svg`: đồi cà phê Bảo Lâm, ánh mật ong, lớp cây trồng rõ.
- `region-da-lat.svg`: vùng Arabica Đà Lạt/Cầu Đất, sương và núi cao.
- `region-langbiang.svg`: đỉnh Langbiang, không khí cao nguyên, tông xanh tím nhẹ.

Khuyến nghị ảnh ngang tỷ lệ 16:10, tối thiểu 1600 × 1000 px, không watermark. Nếu đổi sang `.webp` hoặc `.jpg`, cập nhật `REGION_VISUALS` trong `src/features/home/components/traceability-carousel.tsx`.
